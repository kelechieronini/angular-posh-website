What is Posh?

Posh is a premium Angular website template designed for modern web experiences. It ships with 11 pre-built homepage demos — from digital agencies and restaurants to hotels and e-commerce shops — so you can pick a starting point that fits your project and customize from there.

Built with Angular 21 and Tailwind CSS, Posh gives you a clean, responsive foundation with smooth animations, a polished UI, and a component architecture that keeps your codebase organized as it grows.

Getting Started

After downloading Posh, follow these steps to get it running on your machine.

1. Install dependencies

npm install

2. Start the dev server

ng serve

3. Open in browser

http://localhost:4200
